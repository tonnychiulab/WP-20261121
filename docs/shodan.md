# Shodan（Chrome 擴充功能）簡介

- **工具類型**：Chrome 瀏覽器擴充功能（網路資產與主機情資查詢工具）
- **安裝連結**：[Chrome 線上應用程式商店 - Shodan](https://chromewebstore.google.com/detail/shodan/jjalcfnidlmpjhdfepjhjbhnhkbgleap)
- **擴充功能 ID**：`jjalcfnidlmpjhdfepjhjbhnhkbgleap`

---

## 一句話認識它

**Shodan** 常被稱為「連網裝置的搜尋引擎」。這款官方 Chrome 擴充功能把 Shodan 的情資查詢能力直接整合進瀏覽器——當你瀏覽任何網站時，只要點開外掛，就能立刻看到該網站主機的 **IP 位址、所在地區、所屬機構，以及對外開放了哪些連接埠（Ports）與服務**。

---

## 主要功能特色

1. **瀏覽即查的主機情資**
   開啟網頁時自動透過 Shodan 資料庫查詢目前網域／IP 的已收錄資訊，無須切換分頁或手動下指令。

2. **主機地理位置與網路歸屬**
   - 顯示網站伺服器所在的**國家與城市**。
   - 列出 IP 位址所屬的**組織／雲端服務商（ISP / ASN）**，以及反查到的主機名稱（Hostnames / PTR）。

3. **開放連接埠（Open Ports）與服務一覽**
   清楚標示該主機除了標準網頁服務（如 `80`、`443`）之外，是否還對外開放了其他服務（例如 `22` SSH、`21` FTP、`53` DNS、資料庫或管理後台連接埠等）。

4. **快速檢視與深入調查**
   - 點擊介面中的連接埠或連結，可快速以 `IP:Port` 方式檢視服務，或直接跳轉至 Shodan 網站查看更完整的主機詳情、歷史紀錄與已知弱點資訊。

---

## 常見應用情境

- **自有網站與主機安全健檢**：網站架好上線後（例如 WordPress 主機），快速確認自己是否不小心把不該公開的 Port（如資料庫、測試服務、管理介面）暴露在網際網路上。
- **基礎架構與託管環境識別**：確認網站是否經過 Cloudflare 等代理／CDN，或是直接暴露源站主機 IP。
- **資安研究與教育分享**：在不對目標進行主動掃描的情況下，透過 Shodan 既有的公開索引資料示範「攻擊面（Attack Surface）」的概念。

---

## 快速上手步驟

1. 前往 [Shodan Chrome 線上應用程式商店頁面](https://chromewebstore.google.com/detail/shodan/jjalcfnidlmpjhdfepjhjbhnhkbgleap) 並點選「**加到 Chrome**」。
2. 將 Shodan 圖示釘選（Pin）在瀏覽器工具列上。
3. 瀏覽任一網站時點擊 Shodan 圖示，即可檢視該主機的 IP、所在地、所屬組織與開放連接埠清單。

---

## 注意事項與合規提醒

- **資料性質**：外掛顯示的是 Shodan 資料庫中既有的索引快照，並非即時對目標發動掃描，因此資料可能與當下主機狀態略有時間差。
- **CDN／代理影響**：若網站有套用 Cloudflare 等反向代理或 CDN，Shodan 顯示的會是代理節點的 IP 與開放埠，而非真實源站主機。
- **合法使用原則**：請僅用於自我網站安全檢查、學習研究或經合法授權的資安評估，切勿針對未經授權的外部系統進行未經許可的測試或存取。
